# ☕ Bootcamp Java – DIO

Repositório dedicado aos estudos e projetos práticos desenvolvidos durante o bootcamp **Itaú - Java com Inteligência Artificial**, oferecido pela [DIO](https://www.dio.me/).

O objetivo é consolidar conhecimentos em desenvolvimento de software com Java, aplicando conceitos fundamentais, boas práticas de programação, padrões de projeto, frameworks e integração com tecnologias relacionadas à Inteligência Artificial.

## 📚 Projetos

Os projetos estão organizados em diretórios independentes, agrupados por assunto ou desafio proposto durante a formação.

| Projeto | Descrição |
|---|---|
| [fundamentos](./fundamentos) | Exercícios e estudos dos fundamentos da linguagem Java. |
| [design-patterns](./design-patterns) | Implementações práticas de padrões de projeto utilizando Java. |
| [design-patterns-spring](./design-patterns-spring) | Aplicação de padrões de projeto com o ecossistema Spring. |
| [annotation-processor](./annotation-processor) | Estudos sobre processamento de anotações em Java. |
| [task-manager](./task-manager) | Projeto voltado ao gerenciamento de tarefas. |
| [warehouse](./warehouse) | Projeto voltado ao gerenciamento de armazém. |

## 🛠️ Tecnologias e ferramentas

- **Java:** linguagem principal de desenvolvimento.
- **Spring Framework:** desenvolvimento de aplicações e utilização de seus recursos.
- **Gradle:** gerenciamento de dependências e automação de builds nos projetos configurados com essa ferramenta.
- **JUnit:** testes automatizados.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.
- **Visual Studio Code:** ambiente de desenvolvimento.

## 🎯 Objetivos de aprendizagem

- Consolidar os fundamentos da programação orientada a objetos.
- Desenvolver aplicações utilizando recursos modernos do Java.
- Aplicar padrões de projeto e princípios de organização de código.
- Trabalhar com frameworks e bibliotecas do ecossistema Java.
- Explorar processamento de anotações e recursos avançados da linguagem.
- Desenvolver soluções integradas com tecnologias de Inteligência Artificial.
- Aprimorar práticas de testes, manutenção e qualidade de software.
